## Изменение до первого вызова
1. Перед вызовом читателя код сопоставляет запрошенное окно (диапазон или весь файл) с объединением сохранённых наблюдений той же версии источника (Ref с хэшем, не путь). Полное покрытие: читатель не вызывается, наблюдения доставляются. Частичное покрытие: вход читателя НЕ урезается (полное окно с пометкой уже извлечённых диапазонов, чтобы не отрезать условия и исключения); дедупликация на выходе при извлечении: координаты внутри сохранённых наблюдений доставляются ссылками на них, извлекаются только непокрытые строки. Решение, покрывает ли это новую потребность, остаётся аналитику. Уточнено 2026-09-07, п.9 обсуждения.
2. Прежние unresolved и выводы о полноте не переносятся: они относятся к прежнему назначению; новый вопрос получает свой анализ.

Вид изменения: код сборщика доказательств.

## Тест
- Запрос на источник, полностью покрытый прежними наблюдениями, не вызывает читателя, а доставляет наблюдения; мутация: убрать сопоставление — тест обязан упасть.
- Частично покрытый источник: читатель получает полное окно; извлечение без повторов сохранённых строк; доставка = ссылки на старые наблюдения + новые строки. Мутация «урезать вход» — тест на наличие условий вокруг покрытого участка обязан упасть.
- Другая версия того же источника: покрытия нет, читатель вызывается.
