# Карта прохода OMG — три слоя

`omg-pass-map-2026-10-14.html` собирается, а не правится напрямую. Три слоя:

1. **Схема** — `omg-pass-map.src.html`: стадии → `subs` → `nodes` (`var STAGES`), вся разметка и код страницы, массив `DONE` («Сделано») — пока тоже здесь. Правится вручную или регенерацией.
2. **Тексты** — `omg-pass-map-texts.json`: человеческие описания карточек. Ключ — полный точечный путь элемента, как в `reg()`: `disc.d2.n6`, `con.c3.a.n9`. Значения: `{"plain": "Простыми словами…", "example": "На примере…"}`. Ключи отсортированы.
3. **Сборка** — `build-pass-map.mjs` (Node, без зависимостей): вставляет пары первыми строками `d` каждого элемента и пишет итоговый HTML.

## Как собрать

    node build-pass-map.mjs

Скрипт печатает два списка и падает с кодом 1, если любой не пуст:
- «узлов без описания» — в схеме есть карточка без записи в texts.json;
- «описаний без узла» — ключ в texts.json не нашёл элемента (осиротел: узел переименован/удалён).

Осиротевшие ключи — не терять молча: либо переименовать ключ под новый путь, либо удалить запись.
