# Схема блока OM (проектная)

Источник истины: `om-design.json`. Редактируется на полотне ComfyUI, возвращается импортом.

- `comfy/om_design/` — словарь узлов схемы для ComfyUI (ссылка из `ComfyUI/custom_nodes/om_design`). После изменения словаря перезапустить Comfy Desktop.
- `vocab.mjs` — тот же словарь для скриптов; поля и выходы должны совпадать с пакетом.
- `seed-level0.mjs` — уровень ноль: цель блока, предшественники, выход, решения владельца.
- `export-to-comfy.mjs om-design.json OM-DESIGN.workflow.json` — схема → воркфлоу (потом скопировать в `ComfyUI/user/default/workflows/OM-DESIGN.json`).
- `import-from-comfy.mjs <воркфлоу> om-design.json` — воркфлоу → схема с проверкой «хлеба»: узел без потребителя, механизм без цели, вызов модели без обоснования или потребителя, ворота без кодов отказа, открытые решения владельца.

Типы узлов: цель блока, стадия-предшественник, вход от предшественника, механизм (код), вызов модели, ворота, решение владельца, запись хранилища, выход к компилятору. Связи: RECORD (данные), FLOW (порядок, изменение, решение), у ворот два выхода: пройдено / отказ.
