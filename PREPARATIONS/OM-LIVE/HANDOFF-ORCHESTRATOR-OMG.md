## 1. Что это и зачем

- **Проект OMG** (`~/OMG`) — движок, который сам ведёт разработку: проходит карту проекта блоками, задаёт вопросы модели (OpenAI через Codex CLI), проверяет её ответы и пишет доказательные записи в SQLite-базу.
- **Живой проход** — настоящий прогон движка на живой базе `~/OMG/.omg/state.sqlite`, проект `omg-live`, с платными вызовами модели. Цель — дойти до компилятора.
- **Твоя роль** — оркестратор кода:
  - выдаёшь задачи исполнителям через общий канал;
  - проверяешь сдачи и отдаёшь их на ревью;
  - вливаешь принятое в ветку `om/module`;
  - пересобираешь движок, запускаешь и ведёшь живой проход;
  - докладываешь пользователю.
  - **Продуктовый код сам не пишешь.**
- Главные идеи движка, которые нельзя потерять: доказательность, точные связи, проверка ответов модели, **запрет повторной оплаты** одного и того же ответа.

## 7. Процедуры

**Проверка сдачи исполнителя.** Сдача — сообщение в канале с копией `~/omg-wt/<имя>`, базой, хэшем `git diff | shasum -a 256` и временем полного прогона.
```bash
W=~/omg-wt/<копия>
git -C $W rev-parse --show-toplevel HEAD          # база = нынешняя вершина om/module?
git -C $W diff HEAD | shasum -a 256 | cut -c1-8   # равно хэшу из сдачи?
T=$(GIT_INDEX_FILE=/tmp/x.idx sh -c "git -C $W read-tree HEAD && git -C $W add -A && git -C $W write-tree"); echo $T
# правок после старта прогона быть не должно: сравнить mtime изменённых файлов со стартом из backend-runs.ndjson
tail -2 ~/.asvp-review/backend-runs.ndjson        # end этого прогона с exit 0
```

**Парковка:**
```bash
C=$(git -C $W commit-tree $T -p <база> -m "<сообщение>")
git -C $W update-ref refs/omg-park/<задача>-r<круг> $C
```
Затем `review-request` в codex-omg: сдача, парк, хэш, что проверил, что смотреть.

**Вливание после вердикта «принять»** — только CAS:
```bash
git -C $W update-ref refs/heads/om/module <парк> <прежняя вершина>
```
Если вершина ушла — не вливать, разобраться. Исполнителю — note «ВЛИТ».

**Возврат** — `task` исполнителю с замечанием ревьюера по сути. Порядок тот же: правка → полный прогон → сдача → ревью.
